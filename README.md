# Huzaifa Zuberi — Portfolio

A responsive, single-page portfolio website built for Huzaifa Zuberi, featuring a hero,
about, technical skills, featured projects, experience, and contact sections. Includes
dark/light theme toggle and a mobile menu.

## Tech

- Vanilla HTML / CSS / JavaScript (no build step)
- Font Awesome icons
- Google Fonts (Inter, JetBrains Mono)

## Live Site

Deployed with GitHub Pages: `https://huzaifa-zuberi.github.io/portfolio/`

## Local Preview

Open `index.html` directly in a browser, or run a local server:

```bash
python -m http.server 8000
# visit http://localhost:8000
```

## Deploy

This repo is configured to publish from the `main` branch via GitHub Pages
(`gh-pages` on `main`). Push to the repo and Pages will serve automatically.

To update content, edit `index.html`, `styles.css`, and `script.js`, then commit and push.
